Instructions for Linux Ubuntu 18-20
For additional info or help, please send IM to Sam Adama resident in-world.
Or open a support ticket: https://caprica.xyz/support/

IMPORTANT - HTTPS:
Since November 2026 Caprica public grid services (port 9000) are served over
HTTPS only. This kit is already configured to use https://g.caprica.xyz:9000
for all public services (login, assets, profiles, bakes, map tiles).
Private services on port 8003 remain plain http by design.
The protocol is controlled by BaseScheme / PrivScheme constants in
bin/OpenSim.ini [Const] - https is strongly recommended, do not downgrade
to http unless Caprica support explicitly asks you to.
Details: see README.md "HTTPS - recommended" section.

QUICK SETUP:
After cloning the repository you can run the interactive wizard instead of
manual editing of the config files:
    cd /opt/capricaregion && ./setup.sh
It will ask for your region name, UUID, location, ports, external address,
service protocol (https recommended) and will fill in Regions.ini and
OpenSim.ini for you. Steps 1-3 below describe the same process manually.

Important points.

It is advisable to raise the server to a VPS of one of the hosters.
All listed ports must be accessible from the outside
If the server goes up on a home computer, you must have a static IP. It 
must be accessible from the external network.
Access from some grids is permanently blocked on Caprica (see website).
You can get help with server settings from Caprica Hypergrid support. 
(https://caprica.xyz/support/)

Running WITHOUT a domain (IP only)?
A domain name is NOT required - ExternalHostName may be a plain IP address.
Visitors will reach your region as http://<your-ip>:<port>/ and HG teleports
work the same way. The connection FROM your region TO Caprica is unaffected:
it always goes to g.caprica.xyz:9000 over HTTPS regardless of your address.

Notes for IP-only setups:
- Enter your external IP as ExternalHostName in Regions.ini (setup.sh accepts it).
- The /etc/hosts entry "<your external IP>   localhost" is REQUIRED - OpenSim
  resolves its own ExternalHostName locally.
- Do NOT enable http_listener_ssl for your region's own port: publicly trusted
  TLS certificates are not issued for bare IP addresses, and a self-signed
  certificate will cause warnings in viewers. Plain HTTP on your own port is
  fine - only the Caprica-facing side needs HTTPS (already configured).
- Make sure ca-certificates is up to date on the server
  (sudo apt install --reinstall ca-certificates) so the system trusts the
  Let's Encrypt certificate used by g.caprica.xyz.


-----------------------------------

Preparing:
Register your Avatar here: https://g.caprica.xyz/account/register

In your operation sistem:
sudo apt update && sudo apt upgrade
sudo apt install git
sudo apt install screen
sudo apt install mono-complete
sudo ufw allow 9000,8003,8002 (+ port of your region)
cd /opt
git clone https://github.com/capricagrid/capricaregion.git

-----------------------------------

Step 1.
Open /opt/capricaregion/bin/Regions/Regions.ini
Please, check the Map first, before enter region location! https://caprica.xyz/simple-map/
Change Region name, RegionUUID, Location, SizeX;Y, InternalPort and ExternalHostName to your values.
To generate a UUID for your region, use the Gridlist UUID generator: https://gridlist.ru/uuid/
Save and exit

Step 2.  (optional - MySQL for offline IM)
Open /opt/capricaregion/bin/config-include/GridCommon.ini
[DatabaseService] SQLite works out of the box - database files (*.db) are
created inside the region directory (bin/). NOTE: with SQLite the OfflineIM
module must stay disabled (setup.sh does this automatically), so offline
messages will NOT work. For offline IM, install MySQL
(sudo apt install mysql-server), create a database and user, uncomment
StorageProvider/ConnectionString, fill in credentials, and re-enable
OfflineMessageModule in OpenSim.ini [Messaging].
NOTE: ./setup.sh does all of this interactively.

Step 3   (optional!)
Open  /opt/capricaregion/bin/OpenSim.ini
in line 48 find  http_listener_port and port number, and change it to your port number. Don't forget, this port must be accessible and not blocked by a firewall.
Save and exit

Step 4
Make sure that ports 9000, 8003, 8002, the port you specified in OpenSim.ini configuration file and the port of your region are accessible from outside.
Make sure the settings specified in the "hosts" file are correct:
127.0.0.1   localhost
[your external IP]   localhost

Step 5
cd /opt/capricaregion/bin/
screen -S [name of your region]   ;screen -S myregion (for example).
mono OpenSim.exe

Enter the Estate name.
Enter the first and second name of your avatar registered with Caprica Hypergrid.
Wait for the message "Login enabled" in the terminal.
If you encounter error messages while starting your region, check your settings carefully again.
To exit the "Screen" session, use the keyboard shortcut ctrl+A+D. Instance launched in this "Screen" session will continue to work.
To open the session again, enter the command 'screen -d -r [name of your region]'
Use the help by entering the command 'man screen'

Step 6
Add the CapricaHypergrid address to your client's grid list as shown in step 2 of this tutorial: https://caprica.xyz/services/addcaprica/

Step 7
Login to Caprica Hypergrid with your avatar and find your region on the map by entering your region name. Teleport and make additional settings if desired.

Step 8
Enjoy your Virtual World!
